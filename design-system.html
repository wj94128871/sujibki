0. 원칙

  1. 데이터 우선: 장식보다 수치 가독성·비교·신뢰 표기가 우선.
  2. 한눈에: 6섹션 단일 스크롤, 계층(헤더>카드>차트>상세)이 분명한 시각적 위계.
  3. 신뢰: 저신뢰 수치에 뱃지·주석, 단정 금지 표현은 디자인으로도 유지(절대확정 강조 금지).
  4. 접근성(WCAG AA): 키보드 전용 사용 가능, 명확한 포커스, 충분한 대비.
  5. 토큰 기반: light/dark를 CSS 변수(primitive→semantic→component 3계층)로.

1. 컬러 팔레트

1.1 컨셉

  • 데이터 특성(시장지표·신뢰)을 살리는 중립 배경 + 시그니처 인디고/블루 + 한정적 상태색.
  • 차트는 categorical 순서열(카테고리 구분용) + status 신호색(성공/경고/위험)을 분리 사용.

2. 타이포그래피

  • 폰트: 시스템 폰트 스택(수치 가독성 최우선). 한글·라틴·숫자 혼용 시 system-ui 기반. 숫자는 tabular(고정폭) 정렬로 비교 가독성 확보. (standalone HTML 산출 시 한글 서브셋 내장—기술팀과 협의)
  • 숫자: 모든 지표 숫자는 고정폭(tabular-nums)으로 자릿수 정렬.

2.1 폰트 계층 (Type Scale)

토큰 용도 크기 줄높이 자간(letter-spacing) 두께
--fs-display 헤더 요약 대형 수치 40/32px 1.1 -0.02em 700
--fs-h1 섹션 타이틀 26/22px 1.2 -0.01em 700
--fs-h2 카드 타이틀 18/17px 1.3 0 600

--fs-small 보조·주석·이력 13/12px 1.45 +0.01em 400

  • 자간은 대형 타이틀에서 좁히고(-0.02~-0.01em), 소형 캡션은 넓혀(+0.01~0.03em) 가독·기능 구분.
  • 모바일(≤767)은 위 표의 축소값(표의 / 뒤) 사용.

3. 컴포넌트 규칙

3.1 버튼

유형 크기 규칙
기본(Primary) h:40(모바일 36), px:12/20 배경 --primary, 글자 white/다크 #10141C, radius 8, hover --primary-hover
보조(Secondary) 동일 투명/표면, 1px --border, 글자 --text, hover 배경 --surface-2
텍스트(Link) 동일 배경 없음, 글자 --primary+밑줄 hover, 아이콘 옵션
위험(Danger) 동일 배경 #C0392B/#E2554A, hover 짙게
- 포커스: outline: 2px solid var(--primary) + offset 2px (모든 인터랙티브 요소 공통).
- disabled: 불투명도 40% + cursor:not-allowed, 포커스 불가.

3.2 카드

  • 표면 --surface, 1px --border, radius 12, padding 20/16(모바일).
  • 헤더 영역: 타이틀(--fs-h2) + 우측 액션(필터·더보기).
  • 상태 서브타입: 경고 카드(부분 실패), 성공 카드(완료), 정보 카드(null 주석).
  • 요약 카드: 대형 수치(--fs-display) + 라벨(--fs-small) + 상태 뱃지.

3.3 차트 (외부 CDN 금지 — 번들 내장)

  • 도넛/파이: 카테고리 점유율, 상주vs도급 비중.
  • 바/히스토그램: 예산 구간, 키워드 랭킹.
  • 라인/영역: 월간 등록 추이(다크모드 축·그리드 토큰 반영).
  • 공통 규칙: 축·그리드 --text-3, 데이터 순서 categorical 팔레트, <canvas>는 aria-label+대체 텍스트, 툴팁 키보드 접근, null은 "제외+건수 카운트" 주석, 범례 클릭→해당 시리즈 강조.
  • 키보드 스킴(C4): 차트마다 <canvas> 데이터를 대체하는 스크린리더 전용 <table class="sr-only">(또는 상세 <dl>)를 비표시로 제공. 범례·시리즈 항목은 tabindex="0" + role="button"으로 노출해 Tab/SHIFT+Tab 탐색. Enter/Space로 범례 토글(해당 시리즈 강조). 툴팁은 focus 시 표시 + aria-live="polite"로 읽히고 포커스 유지(hover와 동일 데이터). <canvas>는 aria-label 병기.
  • 제공할 aria-label 예: "카테고리 수요 점유율 도넛 차트, 전체 66,000건".

3.4 신뢰 뱃지

  • 최소 24px 높이, radius 999, 배경·글자색은 1.5절. 아이콘(●◐○) + 텍스트("[신뢰: 높음]") 형태.
  • 반드시 텍스트 포함(색만으로 판단 불가), title/aria-label에 근거 기간·기준 명시.
  • 저신뢰/lower 시 "~로 추정/공지" 문구 함께 표기, 단정 표현 금지.

3.5 빈 상태 / 에러 상태 / 로딩

  • 빈 상태: 아이콘(🗂) + 제목(예: "아직 수집되지 않음") + 설명 + 행동(Call to Action: 수집 실행). 섹션별 문구 분기(미수집/미분석/검색결과 없음).
  • 에러 상태: ⚠ 아이콘 + "데이터를 불러오지 못했습니다" + (재시도)·(자세히: 원인). 재시도 후에도 실패 시 원인 텍스트("원인 미상" 허용).
  • 로딩: section 별 스켈레톤(배경 --surface-2에 shimmer) — 전역 로더 금지. 300ms 이상일 때만 표시(깜빡임 방지).

3.6 테이블/목록

  • 목록 행: 높이 56, hover --surface-2, 클릭 가능 시 캐럿. 필드 열 순서(제목·예산·기간·카테고리·등록일) 고정.
  • 금액은 tabular-nums, "만원→원/월" 정규화된 단위 표기, 예산 "협의 후"는 "협의 후" 라벨.
  • 페이징: ◀ 1 2 3 ▶ + "총 N건" 표시.

3.7 모달 (S-02)

  • 오버레이 배경 40% dim, 패널 --surface radius 16, max-width 560px, 85vh 이내 스크롤.
  • 접근: 포커스 트랩, Esc·배경·(닫기)로 닫힘, role="dialog" aria-modal="true".
  • 필드 null → "정보 없음" 회색.

4. 간격 & 그리드

4.1 간격 스케일 (spacing tokens)

토큰 값
--sp-1 4px
--sp-2 8px
--sp-3 12px
--sp-4 16px
--sp-5 24px
--sp-6 32px
--sp-7 48px
--sp-8 64px
  • 섹션 간: --sp-7(48px) 이상, 섹션 타이틀-콘텐츠: --sp-4(16px), 카드 내용: --sp-4~--sp-5, 카드 간: --sp-4.
  • 4px 단위 규칙으로 일관성 유지(배수만 사용).

4.2 그리드

  • 컨테이너 max-width 1200px, 좌우 padding 24/16(모바일).
  • 카드 그리드: 데스크톱 4열 / 태블릿 2열 / 모바일 1열 (repeat(auto-fit, minmax(240px,1fr))).
  • 차트 그리드: 데스크톱 4열(상단) + 2열(하단: 키워드·추이), 태블릿 2열, 모바일 1열 세로 배치.
  • 모바일(≤767px) 5종 차트 배치(C3): 가로 스크롤 금지. ① 상단 4개 차트(카테고리·예산/기간·상주·키워드)는 세로 1열 카드를 기본으로 하고, 화면이 너무 길어지면 탭형 뷰([점유율 | 예산·기간 | 상주·키워드])로 전환. ② 하단 '월간 등록 추이'는 탭 밖 고정 세로 카드로 유지. ③ 탭은 aria-label+좌우 화살표 키 탐색, 활성 탭 포커스 유지.
  • 목록: 데스크톱 테이블, 모바일 카드형(테이블 대체)·가로 스크롤 최소화.
  • 12-콜럼 기반 / breakpoint: ≥1024 데스크톱, 768–1023 태블릿, ≤767 모바일.

5. 아이콘 & 이미지

  • 아이콘: 외부 CDN 금지 → 라이브러리를 번들 내장(SVG 인라인, currentColor 사용해 다크모드 자동 반영). 스트로크 2px, 16/20/24px 세 단계.
  • 필수 아이콘 세트: 새탭(↗ 외부링크), 검색·필터, 상태(✓성공/⚠경고/✕실패), 신뢰(●◐○), 스크롤 앵커, 다크모드(🌙), 원본, 에러/빈(⚠🗂), 스피너.
  • 아이콘 접근성: 의미 있는 아이콘은 aria-label, 장식 아이콘은 aria-hidden="true".
  • 이미지: 본 대시보드에는 콘텐츠 이미지 없음(데이터·차트 중심). 로고는 SVG(텍스트+심볼). 외부 원본은 링크로만(이미지 미내장).

6. 접근성 (WCAG AA)

6.1 대비 (1.1절 팔레트 준수)

  • 일반 텍스트 ≥4.5:1, 대형 텍스트 ≥3:1. 상태·신뢰 뱃지는 색과 함께 텍스트/아이콘으로 구분.

6.2 키보드 내비게이션

  • 전체 흐름이 Tab/SHIFT+Tab으로 탐색·조작 가능.
  • 모달: 열림 시 첫 요소 포커스 → 포커스 트랩 → Esc 닫힘 → 닫힘 시 트리거 요소로 포커스 복귀.
  • 차트/카드: 범례·시리즈·인사이트 카드를 Tab으로 선택, Enter/Space로 활성화(카테고리 클릭=필터링).

6.3 포커스 상태

  • 모든 인터랙티브 요소: outline: 2px solid var(--primary), outline-offset: 2px. :focus-visible 사용, 키보드 전용 표시.
  • 다크모드에서도 동일 대비 유지.

6.4 기타 WCAG AA

  • 시맨틱 랜드마크: <header><nav><main><section aria-labelledby><footer>.
  • 목적지 앵커: 각 섹션에 id+aria-labelledby, 스킵 링크("본문으로 건너뛰기") 최상단.
  • 동적 콘텐츠: 로딩 완료/에러를 role="status"/aria-live="polite"로 알림.
  • 토스트: role="alert"(aria-live="assertive").
  • 터치 타겟: 최소 44×44px(모바일).
  • 색상 의존 금지: 신뢰·상태는 색+텍스트+아이콘 복합 표기.
  • 모션: 스크롤/전환 애니메이션은 prefers-reduced-motion에서 최소화(부드러운 스크롤 해제).

7. 다크모드 & 반응형 (요약 규칙)

  • 토큰 전환: <html data-theme="dark|light"> + CSS 변수 오버라이드. 초기값 OS 선호(auto), 이후 localStorage 우선.
  • 차트·뱃지·코드 모두 semantic 토큰으로, hard-coded 색 금지.
  • 반응형 규칙: 4.2절 그리드 + 타입 축소(2.1절), 터치 타겟 44px, 테이블→카드 변환.

8. 금지/준수 목록 (개발팀 전달)

  1. 외부 CDN·웹폰트·차트 CDN 사용 금지 → 전부 번들/내장.
  2. 하드코딩 색·간격 금지 → 토큰 사용(design-qa lint로 검증).
  3. 신뢰 뱃지 없이 저신뢰 수치 단정 금지.
  4. client_id(이메일)·개인정보를 어떤 UI에도 노출 금지(NFR-06).
  5. 로그인/권한 UI 없음(NG5), 색상 단독 신호 금지.
