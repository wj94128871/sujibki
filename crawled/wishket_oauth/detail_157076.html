업무 내용

[제안 유형(트랙) 안내]
시스템 구성 중 자체 개발 범위와 상용 기성품(COTS) 활용 범위를 확정하지 않은 상태로 다양한 조합의 제안을 받습니다. 개발과 기성품의 경계는 제안·협의로 정합니다.
- 트랙 A: 전체(하드웨어+소프트웨어) 턴키
- 트랙 B: 소프트웨어·펌웨어만(하드웨어는 발주사 내부/별도)
- 트랙 C: 하드웨어만(소프트웨어는 발주사 내부/별도)
- 트랙 D: 팀 조합(소프트웨어 업체 + 협업 하드웨어 인력)
- 부분 개발: 핵심 1~2종만 자체 개발, 나머지는 기성품 활용도 가능

[프로젝트 개요]
기존 아날로그 전관방송을 5~6종 디지털 장비로 통합하고 IP망으로 연결해 디지털 오디오를 주고받는 시스템입니다. 비상방송은 저지연으로 송출·소방법을 준수하며, 전 장비는 웹브라우저로 설정·운영합니다.

[비즈니스 목표 및 추진 배경]
- 발주사는 방송장비 기업(주력은 영상 분야)으로, 오디오 중심 전관·비상방송은 경험 있는 외부 파트너로 전문성을 확보하려 합니다.
- 기존 아날로그 전관방송은 네트워크 미연결로 타시스템 연동·원격 관리·지능형 비상 대응·다지역 통합 운영이 어렵습니다.
- 목표: 5~6종 장비를 IP망으로 통합해 원격 통합 관리, 지능형·저지연 비상방송, 소방법 준수를 실현합니다.

[기대 효과]
- 원격 통합 관리로 운영 효율 향상, CCTV 등 연동 기반 지능형 비상 대응
- 소방법 준수 저지연 비상방송으로 안전성 확보, 다지역 방송 통합 운영

[과업 범위]
개발사 수행 범위는 트랙에 따라 다르며, 자체 개발과 기성품 구분은 제안 단계에서 협의합니다.
- 공통 플랫폼: 저지연 IP 오디오 전송, 장비 간 제어 프로토콜, 클럭·시간 동기화, 임베디드 웹서버·설정 API, 장비 자동 검색·등록, 원격 펌웨어 업데이트(OTA), 보드 브링업
- Main Control Server: 방송 제어·라우팅, 장치·음원·구역 등록·관리, A/D·D/A 오디오 2채널, 실시간 모니터링·장애 처리, 계정·권한, 방송 이력, 예약 방송, 외부 연동 API(CCTV 등), 다지역 통합 운영
- 비상방송 패널: 비상 마이크 저지연 방송, 우선순위·강제 절체(소방법 페일세이프), 비상음원 자동 재생, 상태 감시
- 디지털 존 매니저: 오디오 매트릭스 분배, DSP 처리(EQ·게인·딜레이·리미터), 스피커 선로 실시간 감시, D/A 출력, 앰프 연동
- 파워앰프: 앰프 제어·보호 펌웨어, 네트워크 직결 오디오 수신, 설정 웹
- 리모트 마이크: 마이크 캡처·송출, 구역 선택·방송 개시, 설정 웹
- 하드웨어: 5~6종 장비의 회로·PCB·기구·부품·조립(트랙에 따라 발주사 또는 제안사)
- 통합·납품: 통합 테스트·시연, 샘플 프로비저닝, 납품 문서(프로토콜 정의서·사양서·매뉴얼)

[요구사항]
역할별 사용자 스토리와 수용 기준(조건-행동-결과)으로 기술합니다.
- 역할: 방송 운영자, 비상 대응자(소방·안전), 유지보수 담당자, 시스템 관리자

1. 등록·방송
- 스토리: 방송 운영자로서 장치·음원·구역을 한 곳에서 등록·관리하고 원하는 구역에 방송·예약 방송하고 싶다
- 수용 기준: 장비 등록 시 목록·대시보드에 즉시 반영·상태 표시되고(신규 장비는 디스커버리 자동 탐지), 구역·음원 방송은 지연 없이 출력, 예약 방송은 지정 시각 자동 시작·기록된다

2. 비상 방송
- 스토리: 비상 대응자로서 비상 시 마이크로 즉시, 일반 방송보다 우선해 방송하고 사후에 확인하고 싶다
- 수용 기준: 비상 마이크 조작 시 저지연 즉시 송출·일반 방송 강제 절체되고, 절체 오류 시에도 페일세이프로 최소 동작이 보장되며, 발생 시각·구역·음원·조작자가 자동 기록된다

3. 감시·원격 관리
- 스토리: 유지보수·관리자로서 선로·장비 이상을 즉시 알고 현장 방문 없이 펌웨어·권한을 관리하고 싶다
- 수용 기준: 스피커 선로·전원·앰프 이상 시 경보·로그가 남고, 펌웨어 원격 배포는 실패 시 이전 버전이 유지되며, 권한 없는 비상방송·설정 변경 시도는 차단·기록된다

4. 확장 연동
- 스토리: 다지역 방송을 통합 관리하고 CCTV 등 외부 이벤트를 비상방송과 연계하고 싶다
- 수용 기준: 지역 선택 시 해당 장비·방송 상태로 화면이 전환되고, 외부 연동 API 이벤트 수신 시 사전 정의 시나리오가 트리거된다(대상·프로토콜 확인 필요)

5. 핵심 시나리오
- 평상시: 운영자가 구역·음원 선택 -> Main Control Server 라우팅 -> 디지털 존 매니저 -> 파워앰프 -> 스피커 출력
- 비상시: 비상 마이크 조작 -> 일반 방송 즉시 중단·저지연 강제 절체 -> 지정 구역 송출·이력 기록(전 과정 선로·전원 실시간 감시)

6. 데이터 주요 엔티티(이름·역할 목록, 상세 구조는 착수 단계 확정)
- 장비/구역/음원, 방송 이력(사후 소명), 비상 이벤트, 계정·권한, 선로·장비 상태, 펌웨어 버전

7. 상태 흐름
- 방송: 대기 -> 요청 -> 일반 방송 -> 종료 -> 대기 (비상 시 일반 방송 -> 강제 절체 -> 비상 방송 -> 해제 -> 대기)
- 장비 등록: 미등록(탐지) -> 등록 대기 -> 완료 -> 이상(경보) -> 복귀
- 펌웨어: 배포 -> 전송 -> 적용 -> 성공/실패(이전 버전 유지)

8. 화면 목록
- 모니터링 대시보드, 장치 등록·관리, 음원·구역 관리, 방송 제어, 이벤트 로그·방송 이력, 계정·권한, 예약 방송, 시스템 설정, 장비별 설정 페이지

9. 외부 연동 요건
- CCTV 등 타시스템 이벤트 연동 API(대상·프로토콜·범위 확인 필요), 기존 아날로그 설비 연동 여부(확인 필요), 다지역 사이트 연동(방식 협의)

10. 비기능 요구사항
- 비상 오디오 저지연(Low Latency) 전송(정량 목표 ms 착수 시 협의), 소방법 준수(강제 절체·페일세이프)
- 장비 간 오디오·시간 동기화, 10대 이상 원격 일괄 업데이트(실패 시 자동 복구), 선로 이상 실시간 감지·경보, 전 장비 임베디드 웹 설정

11. 스코프 밖
- 소방 공인 시험·형식승인 취득 대행, 현장 설치 공사·배선, 기존 아날로그 설비 개보수
- 하드웨어 제작(회로·PCB·기구·부품·조립)은 제외가 아니라 트랙에 따라 포함/제외가 달라지는 협의 대상

[제약 사항 및 확인 필요]
확정 전까지 임의로 정하지 않고 제안·착수 단계에서 협의합니다.
1. 장비 종 수(5/6, 샘플 10/12대) 계약 전 확정
2. 자체 개발 vs 기성품(COTS) 경계
3. 저지연 목표 수치(ms) 착수 후 검증
4. 소방 인증·형식승인 취득 범위(준수 설계·검증 포함, 공인 시험·취득 대행은 별도)
5. 기존 아날로그 설비·CCTV 등 연동 범위·프로토콜
6. BOM·HW 사양(SoC·코덱)은 하드웨어 주체와 공동 결정
7. 하드웨어 수행 주체(회로·PCB·기구·부품·조립)는 트랙에 따라 협의
8. 데이터 구조 상세는 착수 단계 확정
9. 희망 착수일·완료일·예산은 사전 상한 없이 제안 기반 협의

[기술 스택 제안]
제안 값이며 협의로 변경 가능합니다.
- 임베디드 MCU/SoC 펌웨어(RTOS 또는 경량 리눅스), IP 멀티캐스트/RTP 저지연 오디오, PTP/NTP 동기화, 임베디드 웹서버·운영 대시보드, 장비 간 자체 프로토콜(문서 납품)

[예상 예산 및 기간]
- 예상 예산: 협의 결정(사전 확정 상한 없음)
- 예상 기간: 협의(트랙·범위에 따라 상이, 제안 시 예상 기간 제시 요청)

[클라이언트 준비 사항]
- 장비 구성도(예), 기존 설비 배선·사양(연동 시), 소방법 준수 요구 상세
- 소프트웨어만 지원 트랙 시 개발·테스트용 평가보드/시제품 제공

- 착수일·완료일: 협의
- 마일스톤: 트랙 확정·아키텍처/프로토콜 설계 -> 공통 플랫폼(저지연·동기화) -> 장비별 기능 -> 웹·통합 테스트·시연 -> 소방법 검증·납품(트랙에 따라 일부 생략·분담)

[지원 자격 및 우대 사항]
- 수행 가능한 트랙(A/B/C/D·부분 조합) 명시
- 임베디드 펌웨어(MCU/SoC)·IP 저지연 오디오 경험(소프트웨어 트랙), 방송장비 하드웨어(회로·PCB·기구) 경험(하드웨어 트랙)
- 우대: 전관·비상방송·오디오 시스템 이력, DSP 처리, PTP/NTP 동기화, HW·SW 통합(턴키) 이력, 협업 파트너사 네트워크(팀 조합)

[제안 요청 사항]
1. 지원 트랙(A/B/C/D·부분 조합, 자체 개발과 기성품 경계 제안 포함)
2. 5/6종 구성안·근거, 저지연 구현 방식·예상 지연(ms)
3. 유사 프로젝트(전관·비상방송·저지연 오디오·방송장비 HW) 이력
4. 투입 인력 구성·경력·역할(HW/SW 구분), 소방법 준수 설계 방안
5. 예상 기간·투입 규모(트랙·범위 기준, 상세는 접수 후 협의)
6. 팀 조합(트랙 D) 시 협업 파트너사·역할 분담

[산출물]
