0. 여정 개요

주 사용자는 대시보드 단일 페이지에서 ① 전체 요약 → ② 소스별 데이터 → ③ 분석(시장조사·기능방향) → ④ 시장성 인사이트 순으로 내려보며 "현재 시장에서 어느 영역이 유망한가"를 파악한다. 필요 시 소스별 안건 목록·원본 링크로 드릴다운한다.

핵심 여정 흐름 (총 5개):
1. 대시보드 진입·전체 요약 확인 — UJ-1
2. 사이트별 수집 데이터 탐색 — UJ-2
3. 시장조사 분석(수요·트렌드) 확인 — UJ-3
4. 기능 개선 방향·시장성 인사이트 도출 — UJ-4
5. 개별 안건 드릴다운(원본) — 데이터 신뢰 검증 — UJ-5

아래 여정은 텍스트 시나리오. 화면 단위 스토리보드는 디자인팀(storyboard.md)이 작성.

UJ-1. 대시보드 진입 · 전체 요약 확인

목표: 5초 안에 "지금 시장 상황 요약"을 파악.
시작: 팀원이 공유받은 대시보드 URL 접근(로그인 없음).

단계 사용자 행동 시스템 동작 반응
1 URL 접근(브라우저) Pages 로드, 헤더 요약 카드 표시 총 수집 건수·소스별 건수·최근 수집 시각·상태
2 스크롤 없이 요약 확인 소스별 현황 카드(위시켓/프리모아/u300/Devpost) 각 소스 건수·최근 수집·상태
3 "수집 이력" 확인 최근 수집 시각·성공/실패 표시 수집이 신뢰 있음을 확인

성공 기준: 총 건수·소스별·최근 수집이 한 화면에 보인다. · 빈 상태: 데이터 없으면 "아직 수집되지 않음" 안내.
실패 처리: 로딩 스피너 → 에러 메시지 + 재시도.

UJ-2. 사이트별 수집 데이터 탐색

목표: 출처(위시켓 도급, 프리모아 도급, u300 공모, Devpost 해커톤)별로 안건을 파악.

단계 사용자 행동 시스템 동작 반응
1 소스 선택/필터(예: 위시켓) /api/projects?source=wishket 해당 소스 안건 목록(제목·예산·기간·카테고리·등록일)
2 페이지 탐색/검색 페이징·키워드 검색 목록 갱신
3 항목 클릭 /api/projects/:id 경량 상세 DB 필드 기반 상세 + "원본 보기" 링크
4 원본 보기 클릭 새 탭에서 출처 사이트 원문(외부) 출처에서 상세 확인(로그인 항목 포함 시 사용자 판단)

성공 기준: 소스별로 안건을 필터·조회·드릴다운 가능. · 빈 상태: 해당 소스 0건 시 안내.

UJ-3. 시장조사 분석 확인 (수요·트렌드)

목표: 카테고리·예산·기간·기술 키워드·월간 추이로 "시장 수요가 어디에 있는가"를 수치로 확인.

단계 사용자 행동 시스템 동작 반응
1 목록→"시장조사 분석" 섹션 이동(스크롤) /api/analysis 카테고리 수요 점유율 차트 표시
2 예산/기간 분포 확인 집계 차트 예산 히스토그램·기간 분포(null 제외+카운트)
3 상주vs도급 비중 확인 비중 차트 도급/기간제/상주 비율
4 기술 키워드 트렌드 확인 키워드 랭킹 상위 키워드·월간 변화
5 월간 등록 추이 확인 시계열 차트 월별 신규 등록 추이

성공 기준: 5개 분석 차트가 데이터 기반으로 표시. 저신뢰·null은 주석. · 빈 상태: 분석 데이터 부족 시 "분석 미실행" 안내.

UJ-4. 기능 개선 방향 · 시장성 인사이트 도출

목표: "플랫폼/사업을 열면 어느 영역이 시장성 있는가"의 근거 확보.

단계 사용자 행동 시스템 동작 반응
1 "기능 개선 방향" 섹션 확인 /api/insights?type=feature 수요 많고 공급 부족한 영역/요구 패턴 + 근거(건수)
2 "시장성 인사이트" 섹션 확인 /api/insights?type=market 고성장 카테고리/키워드(예: B2B AI 구축) + 추이·근거기간
3 신뢰도 확인 인사이트 신뢰 뱃지(높음/중간/낮음) 저신뢰 수치는 주석과 함께 판단
4 (선택) 참고·기록 복사/메모(외부) 의사결정에 활용

성공 기준: 기능 방향·시장성 인사이트가 수치 근거로 제시되고, 저신뢰 수치가 주석 표기됨(단정 금지). · 빈 상태: 근거 부족 시 "분석 미실행".

UJ-5. 개별 안건 드릴다운 — 데이터 신뢰 검증 (UJ-2 심화)

목표: 대시보드 요약/인사이트의 근거가 되는 개별 안건을 원본에서 검증.

단계 사용자 행동 시스템 동작 반응
1 인사이트/차트에서 특정 카테고리 클릭 해당 카테고리 안건 목록 필터 관련 안건 목록 표시
2 항목 클릭 경량 상세 DB 필드 + 원본URL
3 원본 보기 클릭 외부 출처 새 탭 원문에서 신뢰 검증

성공 기준: 인사이트 → 근거 안건 → 원본으로 이어지는 추적 경로 제공. (SC-2 제대로 된 분석의 신뢰성 지원)
